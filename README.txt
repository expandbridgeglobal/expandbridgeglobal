Before publishing:
1. Edit contact.html and replace hello@expandbridgeglobal.com.
2. Replace https://wa.me/ with your WhatsApp number link.
3. Create a free GitHub account.
4. Create a new public repository, e.g. expandbridge-global.
5. Upload all files.
6. Open Settings > Pages.
7. Select Deploy from a branch, choose main and /root.
8. Save.
9. Your free website will be at https://YOURUSERNAME.github.io/expandbridge-global/

You can later connect a custom domain if you buy one.
